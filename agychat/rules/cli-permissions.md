# CLI Tool Permissions

The user has explicitly granted you permission to run commands using the following CLI tools on their behalf without asking for confirmation first:
- `gh` (GitHub CLI)
- `vercel`
- `render`
- Other standard developer CLI tools

You should assume these tools are installed and use them proactively to accelerate workflows and complete tasks independently. Do not stop to ask if you can use them; just execute the commands.
